you would have to run the det.c file
NO need of any special compiler flags.
./a.out file should finally be executed 
This doesn't work for 1x1 matrix but I could easily solve that issue.

In your terminal run: 
gcc det.c 
then execute .out file:
./a.out

You will be asked to enter size of matrix(n) for which you will have to individually enter the values at each matrix position. After which the determinant will calculate the det value. in the last line.
